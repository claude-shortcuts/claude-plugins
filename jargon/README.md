# jargon

Dial technical vocabulary up or down.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install jargon@prompt-shortcuts
```

## Usage

```
/jargon <high|low> <topic>
```

## Examples

```
/jargon low how TLS certificate chains work
```
Plain language, every term unpacked as it appears.

```
/jargon high how TLS certificate chains work
```
Full domain terminology, nothing padded out.

## Notes

Changes the wording, not the substance — the same facts either way. Use /audience when you want the actual content to change too.
