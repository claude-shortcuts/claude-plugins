# exec-summary

Recast something long for whoever has to decide on it.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install exec-summary@prompt-shortcuts
```

## Usage

```
/exec-summary <text>
```

## Examples

```
/exec-summary <paste a postmortem>
```
Takeaways, what they mean, and what needs deciding.

```
/exec-summary <paste a quarter of notes>
```
Written for someone who won't read past it.

## Notes

Aimed at a decision-maker, so it leads with what needs a call. Use /tldr instead when you just want the gist for yourself.
