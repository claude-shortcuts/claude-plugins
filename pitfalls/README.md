# pitfalls

Stress-test a plan before committing to it.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install pitfalls@prompt-shortcuts
```

## Usage

```
/pitfalls <plan|idea>
```

## Examples

```
/pitfalls migrating auth over a single weekend
```
What's most likely to go wrong, why, and the early signal for each.

```
/pitfalls <paste a rollout plan>
```
Focuses on failure modes rather than restating the plan.

## Notes

Deliberately one-sided toward what could go wrong — it is a stress test, not a balanced review.
