# checklist

Turn a task or document into checkbox items.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install checklist@prompt-shortcuts
```

## Usage

```
/checklist <task|text>
```

## Examples

```
/checklist launching a new API version
```
Each item one concrete action, ordered to work top to bottom.

```
/checklist <paste an RFC>
```
Pulls the actionable items out of prose.

## Notes

Best for work done repeatedly or reviewed before shipping. Each item is self-contained, so it survives being pasted into a ticket.
