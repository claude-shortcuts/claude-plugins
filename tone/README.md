# tone

Set the emotional register without changing the content.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install tone@prompt-shortcuts
```

## Usage

```
/tone <mood>: <topic>
```

## Examples

```
/tone warm: tell a candidate we're passing on them
```
Same message, softer register.

```
/tone blunt: explain why this PR can't merge
```
Direct, no cushioning.

```
/tone urgent: ask the vendor to escalate
```
Conveys priority without changing the ask.

## Notes

Shapes word choice and rhythm; the substance stays the same. Formal, casual, persuasive, blunt, warm, and urgent all work.
