# tldr

Compress something long into a scannable TL;DR.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install tldr@prompt-shortcuts
```

## Usage

```
/tldr <text>
```

## Examples

```
/tldr <paste a long thread>
```
One-line takeaway, then only the points that matter.

```
/tldr <paste an RFC>
```
Drops everything that isn't load-bearing.

## Notes

For getting the gist yourself. Use /exec-summary when the audience has to make a decision.
