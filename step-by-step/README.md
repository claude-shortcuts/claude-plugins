# step-by-step

Get ordered instructions with no gaps.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install step-by-step@prompt-shortcuts
```

## Usage

```
/step-by-step <task>
```

## Examples

```
/step-by-step set up local dev for this repo
```
Numbered steps, one action each, nothing assumed between them.

```
/step-by-step rotate our signing keys
```
Followable start to finish without filling in blanks.

## Notes

For a process someone follows once, front to back. Use /checklist for something verified repeatedly instead.
