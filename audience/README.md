# audience

Frame an explanation for whoever has to read it.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install audience@prompt-shortcuts
```

## Usage

```
/audience <who>: <topic>
```

## Examples

```
/audience new hire: how our deploy pipeline works
```
Assumes no internal context and spells out the jargon.

```
/audience CEO: why the migration slipped a quarter
```
Cuts the mechanics, keeps the impact.

## Notes

Changes what is assumed known and what is left out entirely — not just the reading level.
