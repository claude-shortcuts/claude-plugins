# briefly

Get a short answer, not a full explanation.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install briefly@prompt-shortcuts
```

## Usage

```
/briefly <question>
```

## Examples

```
/briefly is Postgres or MySQL better for this?
```
A couple of sentences, no survey of both ecosystems.

```
/briefly what does this regex do?
```
One line.

## Notes

No preamble, no padding, no restating the question. Reach for a normal prompt when you actually want the reasoning.
