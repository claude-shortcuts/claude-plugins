# format-as

Shape the answer into whatever form you name.

## Install

```
/plugin marketplace add claude-shortcuts/claude-plugins
/plugin install format-as@prompt-shortcuts
```

## Usage

```
/format-as <shape>: <topic>
```

## Examples

```
/format-as table: our four candidate queue backends
```
Real columns and rows, not bulleted prose.

```
/format-as email: tell the team the launch moved
```
Ready to send.

```
/format-as FAQ: our new on-call policy
```
Questions people would actually ask.

## Notes

The form drives the structure, not just the styling. Table, bullets, email, memo, FAQ, and blog outline all work.
